## 1. 導入と初回起動

- [ ] APK を A57 にインストールできる。
- [ ] アプリ名、アイコン、Development / Production の区別が正しい。
- [ ] 初回起動で白画面が長く出ず、自然なローディング表示から Web へ移る。
- [ ] Development が `https://dev.munitter.com` を開く。
- [ ] HTTP、SSL 警告、mixed content の許可を求められない。
- [ ] ステータスバー、ナビゲーションバー、下部 Web ナビが重ならない。
- [ ] WebView のバージョンと接続先を、秘密情報なしで試験記録へ残す。

## 2. 認証

- [ ] メールログインを完了できる。
- [ ] Turnstile が表示され、challenge を含め完了できる。
- [ ] サードパーティ Cookie 無効の既定設定で Turnstile を完了できる。
- [ ] X OAuth が同じ WebView 内で開始し、X の認可画面を表示する。
- [ ] X OAuth が `/Auth/XCallback` からむにったーへ戻り、ログインを完了する。
- [ ] 通常の X 外部リンクは標準ブラウザーで開き、OAuth 遷移とは区別される。
- [ ] アプリを終了・再起動してもログイン状態を維持する。
- [ ] バックグラウンド復帰後もログイン状態を維持する。
- [ ] ログアウトでセッションが終了し、再ログインできる。
- [ ] 認証途中の回転・バックグラウンド復帰で二重送信や無限リロードが起きない。

## 3. Home、プロフィール、戻る操作

- [ ] Home が表示され、無限スクロールできる。
- [ ] おすすめ / フォロー中を左右スワイプできる。
- [ ] サイドバーを開閉でき、二重表示や残留 overlay がない。
- [ ] プロフィールのタブを左右スワイプできる。
- [ ] 投稿詳細へ移動し、Web 内の戻る操作で元の位置へ戻る。
- [ ] Android の戻るボタン / 予測型戻るジェスチャーが自然に動く。
- [ ] 画像カルーセルのスワイプがタブや戻るジェスチャーと競合しない。
- [ ] 画像ビューアのピンチ、スワイプ、閉じる操作が動く。
- [ ] モーダル、サイドバー、画像ビューア表示中の戻る操作を各々確認する。
- [ ] WebView 履歴がない状態の戻る操作でアプリを自然に終了する。

## 4. 投稿とメディア

- [ ] 単一画像を Photo Picker から選び、投稿できる。
- [ ] 複数画像を選び、順序と枚数を確認して投稿できる。
- [ ] 動画を選び、投稿・インライン再生・プレイヤー操作ができる。
- [ ] カメラ撮影を選び、撮影・確定・キャンセルできる。
- [ ] 通常のファイル選択フォールバックが動く。
- [ ] chooser のキャンセル後に、次の選択を正常に開始できる。
- [ ] 選択中の回転・Activity 再生成で callback の二重完了や古い URI の混入がない。
- [ ] 大容量動画の選択時にフリーズや不要なアプリ側圧縮がない。
- [ ] ストレージ全体の権限を要求しない。
- [ ] 投稿画面でキーボードが入力欄・送信操作を隠さない。
- [ ] プロフィール画像とグループ画像を選択できる。
- [ ] 認証付きダウンロードがある場合、Cookie 不足や外部への署名 URL 漏えいなく完了する。

## 5. DM、SignalR、Spaces

- [ ] DM 一覧から詳細へ移動し、戻れる。
- [ ] DM 入力欄がキーボードで隠れない。
- [ ] DM で画像・動画を選択し、キャンセルもできる。
- [ ] 別アカウントからの DM を `/hubs/dm` 経由でリアルタイム受信する。
- [ ] 通信切断後に DM の SignalR 接続が復旧し、重複表示しない。
- [ ] Spaces の参加・復帰と `/hubs/spaces` の再接続を確認する。
- [ ] Spaces がマイクを要求した時だけ Android の `RECORD_AUDIO` 許可が出る。
- [ ] マイクを拒否した場合にクラッシュせず、再試行可能な表示になる。
- [ ] むにったー以外の origin からのマイク要求を許可しない。
- [ ] WebRTC カメラと位置情報の要求が許可されない。

## 6. 通知、外部遷移、特殊 URL

- [ ] Web の通知画面を表示できる。
- [ ] Android 13以降で通知権限が認証済み画面の表示後に一度だけ要求され、拒否後もアプリを利用できる。
- [ ] 通知Channel `munitter_notifications` が存在し、badge／通知ドットが端末設定で許可されている。
- [ ] Development通知APIの未読通知がAndroid通知領域へ表示され、ホーム画面のアプリアイコンに通知ドット／badgeが付く。
- [ ] 通知タップで既存singleTask WebViewが再利用され、対象URLまたはNotificationsへ遷移する。
- [ ] Web側で通知を既読化すると、次回同期でOS通知とbadgeが消える。
- [ ] 一般外部 HTTPS リンクが標準ブラウザーで開く。
- [ ] 内部 HTTPS リンクが WebView 内で開く。
- [ ] `mailto:` と `tel:` は対応アプリがある場合だけ安全に開く。
- [ ] `intent:` は解決可能な安全な Intent だけを開き、fallback でクラッシュしない。
- [ ] HTTP、`file:`、`javascript:`、不明 scheme を WebView 内で開かない。
- [ ] `window.open` / 新規タブ相当のリンクで、内部・OAuth・外部の規則が維持される。

FCM と App Links は未導入である。WorkManager同期は端末のバックグラウンド制限と最短15分周期の影響を受けるため、FCM相当の即時性やアプリforce-stop中の受信を合格扱いにしない。

## 7. 障害、復帰、表示

- [ ] 機内モードでオフライン表示になり、再読み込みできる。
- [ ] DNS 失敗、タイムアウト、サーバー 5xx を可能な範囲で区別する。
- [ ] SSL エラーで「続行」を提供しない。
- [ ] 認証中・投稿送信中に自動再読み込みしない。
- [ ] Wi-Fi / モバイル通信の切替後に再接続できる。
- [ ] 低速通信でローディングが固着せず、重複送信しない。
- [ ] バックグラウンド復帰後に画面・スクロール・再生状態が不自然に初期化されない。
- [ ] 縦横回転後に致命的なレイアウト崩れや WebView の重複がない。
- [ ] Android の文字サイズ変更で主要操作が失われない。
- [ ] ダークテーマと Web 側テーマを切り替えても可読性を保つ。
- [ ] アプリ終了後の再起動で Cookie と通常の閲覧状態が不必要に消えない。

## 8. Production 最小確認

- [ ] Production variant の接続先が `https://munitter.com` だけになっている。
- [ ] WebView デバッグが無効である。
- [ ] Development 専用表示・ログがない。
- [ ] Production ログに Cookie、token、署名 URL、投稿・DM 内容がない。
- [ ] 仮 Application ID の APK を Play Store 公開物として扱っていない。

## 不合格時の記録

次だけを記録し、秘密値は保存しない。

- 発生日時、variant、画面、直前操作、再現率。
- Android / WebView version、ネットワーク種別。
- URL は origin と path まで。query 値はマスクする。
- console / network のエラー種別。Cookie、Authorization、Turnstile / OAuth 値は除外する。
- 回転、復帰、権限状態、外部アプリ遷移の有無。
